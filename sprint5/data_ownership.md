# Границы PostgreSQL и MongoDB

## PostgreSQL

В текущей реализации PostgreSQL — источник истины для всей модели, включая переменные параметры в `jsonb`:

- клиенты, сотрудники, идентификаторы техники и её категории;
- заявки, их статусы и история, неисправности, назначения и результаты диагностики;
- нормы ремонта, услуги, сметы и их версии, выполненные работы;
- запчасти, движения склада, счета и оплаты.

## MongoDB

В целевой учебной модели MongoDB хранит определения категорийно-зависимых полей и два набора параметров:

- постоянные характеристики конкретного устройства (`device.parameters`);
- параметры, зафиксированные при конкретном приёме (`service_order.reception_parameters`).

Это разные данные: характеристики устройства не меняются от обращения к обращению, а параметры приёма относятся к одной заявке. Фото и документы в описании модели не предусмотрены.

## Задачи для документной модели

- При регистрации и просмотре техники диспетчер работает с набором постоянных характеристик, состав которого зависит от категории.
- При оформлении каждой заявки диспетчер записывает и просматривает отдельный набор параметров приёма. Его значения относятся только к этому обращению.

В обоих случаях набор полей зависит от категории, поэтому документ естественно представляет эти параметры как единый объект. Характеристики техники и параметры приёма хранятся раздельно из-за разного срока жизни и связываются с данными PostgreSQL по идентификаторам.

## Ограничение

Текущий PostgreSQL `jsonb` уже покрывает эти данные; отдельный выигрыш MongoDB не подтверждён. MongoDB используется только для учебной модели.

## Источники истины и связь данных

- В текущей реализации PostgreSQL — источник истины для всех данных. В целевой учебной модели MongoDB будет источником истины для определений полей и двух наборов параметров; PostgreSQL — для остальных данных.
- Документы MongoDB ссылаются на `device.id` или `service_order.id`. Между базами нет внешнего ключа; приложение проверяет наличие связанной записи в PostgreSQL.
- В учебной целевой модели параметры переносятся в MongoDB без редактируемой копии в PostgreSQL.
